# Task 1 - AI Assisted API Debugging

## Description

This project demonstrates how Generative AI can be used to identify and fix bugs in an Express.js REST API.

## Technologies

- Node.js
- Express.js
- Git
- ChatGPT

## Prompt Engineering Techniques

- Zero-shot Prompting
- Chain of Thought (CoT)
- Role-Task-Format (RTF)

## Bugs Fixed

- Missing JSON middleware
- Wrong HTTP method
- Incorrect DELETE response
- Invalid server port

## How to Run

```bash
npm install
node server.js
```
