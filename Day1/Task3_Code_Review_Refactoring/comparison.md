# Before vs After Comparison

| Before                 | After                       |
| ---------------------- | --------------------------- |
| Single server.js file  | MVC Architecture            |
| Callback functions     | async/await                 |
| No validation          | Input validation            |
| Weak error handling    | try/catch                   |
| Mixed responsibilities | Separation of concerns      |
| Hard to maintain       | Easy to maintain and extend |
